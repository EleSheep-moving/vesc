# 固件速度环与本库参数的单位参考

本库 Kv 单位 s⁻¹；电流增益为 Kv*g(a_ref)，不能直接填入 VESC 的 s_pid_kp。
按用户 6.05 参数、3465 ERPM/(m/s)、名义有效电流量程 120 A，
固件 P 为 83.16 A/(m/s)，局部相当于 B/C 端 Kv=8.744/10.758；降额会改变该量。
